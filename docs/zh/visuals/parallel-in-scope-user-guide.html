v0.2 使用入口

旧交互式页面使用了已移除的 ParConfig 和 ParOptions。当前 API 先构建 GlobalPar，再从其中取得已绑定执行器的 Par。

GlobalPar global = GlobalPar.builder()
    .register("io", executor)
    .build();

MultiTaskOptions options = MultiTaskOptions.of("fetch")
    .parallelism(8)
    .timeout(Duration.ofSeconds(3))
    .build();

global.par("io").map(items, client::fetch, options);

请以 完整使用指南 为准；从 `0.1.x` 升级请先查看 v0.2 迁移指南。
