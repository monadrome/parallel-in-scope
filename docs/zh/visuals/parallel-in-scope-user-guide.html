v0.3 使用入口

旧交互式页面使用了已移除的 ParConfig 和 ParOptions。当前 API 先构建 ParRuntime，用 String 名注册执行器，再从其中取得已绑定执行器的 Par。

ParRuntime global = ParRuntime.builder()
    .register("io", executor)
    .build();

BatchOptions options = BatchOptions.timeout("fetch", Duration.ofSeconds(3)).parallelism(8);

global.par("io").map(items, client::fetch, options);

请以 完整使用指南 为准；从 0.2.x 升级请查看 v0.3 迁移指南，更早版本请查看 v0.2 迁移指南。
