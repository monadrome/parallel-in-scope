v0.3 执行架构

此页面已随 v0.3 重构：旧图中的 ParConfig、ParOptions 和运行期执行器解析不再存在，ParName 已更名为 ParId。

应用装配：ParRuntime 以 String 名注册多个 Par，并在构建期将每个入口绑定到 supplied executor。

结构定义：ParRuntime.defineGroup* 生成只含结构的不可变 TaskGroupDefinition（成员与终端 combine 返回类型化 Member 句柄），可跨线程复用。

单次调用：批次用 BatchOptions、成员用 TaskOptions 解析为 MultiTaskContext；任务组经一次性的 Bindings 在 submitGroup 边界统一接纳。

执行与观测：滑动窗口提交在取消或拒绝后为未提交任务写入终态；组完成经 completionFuture() 与调用方选择的 executor 回调观测。

维护：取消发生在执行前时，按物理线程池 identity 合并 purge 维护。

完整说明请阅读 使用指南、v0.3 迁移指南、v0.2 迁移指南 和 ADR 0005。
