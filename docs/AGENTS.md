# Documentation Routes

## Exploratory Design

For option generation, use this directory only for explicit requirements and design principles
routed by the task. Quickstarts, user guides, examples, feature claims, and current usage patterns
belong to the candidate-evaluation load defined under `Exploratory Design Loading` in
[root AGENTS.md](../AGENTS.md).

Before recommendation or implementation, inspect every page affected by surviving candidates and
record observable-behavior, navigation, example, and migration impacts. Current documentation is
an impact inventory, not a requirement to preserve the current design.
