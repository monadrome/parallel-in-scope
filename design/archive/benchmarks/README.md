# 性能探针（不参与 Maven 构建）

这里的独立 Java 程序用于复现性能结论与对照实验。它们不在 `src/main/java` 下，也不由
`pom.xml` 编译；按需用 `javac`/`java` 单独运行。

- 只增不改；新的实验放新文件，并在文件名或注释里写明日期与目的。
- 性能结论写入 `BACKLOG.md`、设计文档或提交说明时，必须给出可复现的命令与输入规模，
  不要只引用提交 hash。
- 这些探针不是库的公开 API，可以随实验淘汰；淘汰前确认结论已落到上述文档。

本目录在 2026-10-31 重新入库，用于移除 `BACKLOG.md` 对提交 hash 的取回依赖。
