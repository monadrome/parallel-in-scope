# 设计归档（非契约）

本目录存放**冻结的历史文档**：已否决、已被取代或已收割的提案与分析。它们只用于追溯
当时的结论、否决理由与取舍，**不约束当前实现**。现行约束见
[../AGENTS.md](../AGENTS.md) 路由表中的活契约。

维护规则：

- 只增不改。已入库的归档文档不再编辑；需要补充说明时在 `decision-log.md` 写指针。
- 新决策不写在这里；结论进 [../decision-log.md](../decision-log.md)，跨模块决定进
  [../../adr/](../../adr/)，单一契约的取舍进对应活契约的「被排除的替代方案」。
- 引用归档文档时使用相对路径链接，不要用提交 hash 或行号定位内容。

本目录在 2026-10-31 重新入库。此前 `archive/` 被删除，文档只能靠提交 hash 取回，
一旦历史被重写或克隆不完整就会失效。
